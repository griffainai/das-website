# Touchdown — a11y-landmarks #12

## Aim
The deliberate pass I promised in job #10: give every page a main landmark and a working skip link (WCAG 2.4.1 Bypass Blocks).

## What it was told
"keep going" while ODNDR DNS stays blocked.

## What it did
- Tried the accesslint MCP first for real audit data; its CDP kept colliding with the running Chrome (`Unexpected token 'v', "var Access"`) on both audit_live and audit_html. Abandoned the tool rather than burn the session on it, and did the work from the structural evidence already gathered.
- **Safety check BEFORE touching markup:** grepped the stylesheet for `body > x` selectors — zero. Wrapping content in a new element could not break layout.
- 32 pages: content wrapped in `<main id="main">`, inserted after the mobile-drawer block and closed before `<footer class="footer">`; each file verified (exactly one main, opens before the footer) before writing — 0 failures.
- 18 pages already had a `<main>`: gave it a stable id where missing, left its classes alone.
- All 50: skip link as the first child of `<body>`, `.skip-link` CSS (offscreen until focused), css cache-bumped to v14.
- Second pass: `tabindex="-1"` on every main. Without it the skip link only *scrolls* — focus stays in the nav, so a keyboard user lands visually in the content with their focus ring still behind them.

## How it went
Grade: 4 — the verify-then-write discipline paid: no page was written unless its own structural assertions passed, and the CSS safety check made the wrap provably non-breaking.

The verification itself taught the real lesson. My first live check reported the skip link "not visible on focus" — I nearly logged that as a bug. It was `document.hasFocus() === false`: a browser window without OS focus does not match `:focus`, so the reveal never fires. Proven by re-testing in a focused window: `matchesFocus: true`, `left: 0px`, width 190px, on-screen. The focus-move test then confirmed `focusMovedToMain: true`. A screenshot confirmed layout is unchanged after wrapping.
